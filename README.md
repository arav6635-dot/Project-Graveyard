# Project Graveyard

Modern black/blue web app where developers submit dead side projects, crowd-tag why they failed, and extract patterns across all failed experiments.

## Features
- Simple developer submission form (core fields only)
- Crowd voting on failure causes per project
- Tagging system for pattern slicing
- Gemini-powered AI autopsy per project (`gemini-2.5-flash`)
- Gemini-powered Failure Pattern Console generated from existing graveyard projects
- SQLite persistence for long-term failed-experiment dataset

## Gemini-only mode
This app runs in **Gemini-only AI mode**.
- No local heuristic analysis
- No fallback model
- `GEMINI_API_KEY` is required for:
  - `POST /api/projects/<id>/analyze`
  - `GET /api/analytics/overview`

## Run
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# Add your real key in .env or export it in your shell
python app.py
```

Open `http://127.0.0.1:5000`

## Notes
- Portfolio analytics are generated by Gemini from the current project dataset and cached by dataset fingerprint.
- Analysis reports are persisted and shown in each project card.
